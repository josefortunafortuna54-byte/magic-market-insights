# Design — Internacionalização (i18n) TMT

> Data: 2026-08-15 · Branch: `feature/i18n`
> Decisões do dono do produto (aprovadas em brainstorming 2026-08-15):
> - 14 idiomas: pt, en, es, fr, ja, ln (lingala), de, it, nl, zh, ko, ru, sw (suaíli), ar.
> - Abordagem **A: i18next + react-i18next + expo-localization**.
> - Traduções **geradas** (PT é a fonte; restantes geradas por IA).
> - Idioma inicial: **deteção do dispositivo** (expo-localization) com fallback pt; escolha do utilizador guardada **localmente** (AsyncStorage).
> - Toggle no **Perfil** → ecrã "Idioma".
> - **Árabe em LTR** nesta fase (sem RTL completo).

## 1. Objetivo

Tornar a app (todos os ecrãs e componentes) traduzível para 14 idiomas, com deteção do idioma do dispositivo, escolha manual persistida no Perfil e re-render instantâneo ao mudar. PT é o idioma de origem/fallback.

## 2. Dependências

- `i18next` + `react-i18next` — motor de tradução (interpolação, plurais, aninhamento).
- `expo-localization` — deteção do idioma do dispositivo.
- Instalar com `npx expo install i18next react-i18next expo-localization` (versões compatíveis com SDK 56).

## 3. Arquitetura

```
src/lib/i18n/
  index.ts                  init i18n (resources, fallbackLng, initReactI18next)
  index.tsx                 <I18nextProvider>/Context opcional
  locales/pt.json           fonte (todas as chaves)
  locales/en.json, es.json, fr.json, ja.json, ln.json,
  de.json, it.json, nl.json, zh.json, ko.json, ru.json,
  sw.json, ar.json
  languages.ts              LANGUAGES: [{ code, label (nome nativo), emoji/bandeira }]
```

- **Inicialização:** no arranque da app (antes dos ecrãs), lê `AsyncStorage['app_language']`; se vazio, usa `expo-localization.getLocales()[0].languageCode` mapeado para os 14 códigos (`pt-PT→pt`, `zh-CN→zh`, `en-US→en`, …) com fallback `pt`.
- **Mudança de idioma:** `i18n.changeLanguage(code)` + guardar em AsyncStorage → `useTranslation()` re-renderiza todos os componentes; `fallbackLng: 'pt'` cobre chaves em falta.
- **Tipos:** tipar as chaves (`react-i18next` `resources` augmentation) para detetar chaves órfãs em tsc.
- **Datas:** onde simples, substituir `toLocaleString('pt-PT', …)` pelo idioma ativo (`new Date().toLocaleTimeString(i18n.language, …)`); números mantêm-se.

## 4. Ecrã "Idioma" (toggle no Perfil)

- **`perfil.tsx`:** nova row "Idioma" (ícone globo) na secção de definições → `router.push('/idioma')`.
- **Novo `src/app/idioma.tsx`:** lista das 14 línguas com nome **no próprio idioma** + bandeira; check no idioma atual; toque → `changeLanguage` + persistir → **re-render instantâneo**.
- **`_layout.tsx`:** registo da rota `idioma` (modal, título "Idioma").

## 5. Escopo de tradução

- Todos os **23 ecrãs** (`src/app/**`) e **componentes partilhados** (`ui.tsx`, `SectionHeader`, `PlanCard`, `BoomCard`, `DashboardHeader`, `PerformanceCard`, `AiFab`, `WalletCard`, `SignalCard`, `GradientCard`, `NextBoomCard`, `PriceTicker`, …) — texto PT hardcoded → `t('chave')`.
- Hooks/lib com texto visível ao utilizador: `notifications.ts` (títulos/body), `signalNotifications.ts`, `boomPrefs`, mensagens de erro/empty states.
- **Admin** incluído.
- **pt.json é a fonte**; gerar os 13 restantes com as mesmas chaves.

## 6. Testes / verificação

- `npx tsc --noEmit` + `expo lint` limpos (baseline obrigatório).
- Verificação de chaves: nenhuma `t('x')` órfã (tipagem de recursos + grep).
- E2E browser (Playwright): Perfil → Idioma → EN → verificar ecrãs principais; Lingala e Árabe renderizam; voltar a PT; reload → escolha persiste; idioma de dispositivo não suportado → fallback pt.

## 7. Fora de alcance

- RTL completo (AR renderiza LTR).
- Traduções comunitárias/por utilizador.
- Tradução de conteúdo do servidor (mensagens de bot, conteúdos admin) — é conteúdo, não UI.
